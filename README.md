# unit-converter-python
Unit Converter (Python)

A simple command-line Unit Converter built using Python. This project allows users to convert between common units through a menu-driven interface.

Features

- Kilometers to Miles
- Miles to Kilometers
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Simple and easy-to-use console interface

Technologies Used

- Python 3

How to Run

1. Clone this repository:
   git clone https://github.com/your-username/unit-converter-python.git
2. Navigate to the project folder:
   cd unit-converter-python
3. Run the program:
   python unit_converter.py

Example

===== UNIT CONVERTER =====
1. Kilometers to Miles
2. Miles to Kilometers
3. Celsius to Fahrenheit
4. Fahrenheit to Celsius

Enter your choice (1-4): 1
Enter kilometers: 10
Miles = 6.21371
